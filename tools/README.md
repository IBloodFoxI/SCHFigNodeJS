# Проверка бэкенда

Скрипты гоняют живой бэкенд по протоколу backend2. Клиент Figura для них не
нужен: токены stateless, поэтому подделываются тем же HMAC, которым их подписывает
плагин — достаточно знать `secret` из его конфига.

Запускать при поднятом сервисе. Второй аргумент — порт, по умолчанию 8080.

```bash
python tools/apitest.py <secret> [порт]
```

```bash
python tools/wstest.py <secret> [порт]
```

```bash
python tools/admintest.py <secret> <admin-token> <порт> <путь к каталогу data>
```

Всё на чистом Python, без зависимостей — `wstest.py` собирает WebSocket-кадры
руками, `admintest.py` лезет в каталог данных напрямую, чтобы состарить файл и
подложить мусор.

## Что проверяет apitest.py

Гоняет полный цикл жизни аватара под **offline-UUID третьей версии** — тем самым,
что Velocity/nLogin выдают пиратке:

* `/version` без токена — 200; `/limits` без токена и с подделанным — 401;
* `/limits` отдаёт `maxAvatarSize` из конфига, а не зашитые 102400;
* загрузка аватара на 150 КБ проходит (официальный бэкенд отказал бы),
  на 600 КБ — отклоняется по `max-avatar-size`;
* `equip`, профиль с верным sha256, скачивание байт-в-байт, удаление, 404 после.

## Что проверяет wstest.py

* upgrade до вебсокета, `TOKEN` -> `AUTH`, разрыв на мусорном токене;
* подписка `SUB`, ретрансляция пинга подписчику с верными uuid/id/данными;
* `UNSUB` действительно прекращает ретрансляцию;
* пинг больше `ping-size-limit` не ретранслируется, автору уходит `NOTICE`.

## Что проверяет admintest.py

Очистку места и административные маршруты:

* `admin/stats` с верным токеном, 401 с неверным и без;
* при пустом `FIGURA_ADMIN_TOKEN` маршруты вообще отвечают 404;
* состаренный на 200 дней аватар удаляется по `sweep`, аватар активного игрока
  остаётся; профиль удалённого тоже сносится;
* подложенный `.tmp` подчищается заодно;
* `admin/purge/<uuid>` удаляет аватар, и после этого отдача даёт 404 — то есть
  кэш хэшей внутри сервиса действительно сброшен, а не отдаёт мёртвую запись.

## Чего они НЕ проверяют

Выдачу токена по plugin channel `figura:backend` — для этого нужен живой
форкнутый клиент. Скрипты входят «сбоку», сразу с готовым токеном.
